## ระบบทำอะไร

ระบบกันขโมยที่ทำงานแบบ Finite State Machine 6 สถานะ เมื่อเปิดระบบแล้วมีความเคลื่อนไหวผ่านเซ็นเซอร์
ระบบจะให้เวลา 15 วินาทีในการกดรหัสปลดล็อค หากกดไม่ทันจะส่งเสียงไซเรนแจ้งเตือน

```
DISARMED ──[S1]──> ARMING ──[10 วิ]──> ARMED
    ^                                    │
    │                          [PIR ตรวจพบ / กด S1]
    │                                    v
 UNLOCK <──[รหัสถูก]── ALARM <──[15 วิ]── TRIGGERED
    │                    ^                 │
    └──[1.5 วิ]──>       └──[รหัสถูก]──────┘
```

**รหัสปลดล็อค** S1 → S3 → S2 → S1 (แก้ได้ที่ `SECRET_CODE[]`)

| สถานะ | จอ 7-Segment | ไฟ LED | เสียง |
|---|---|---|---|
| DISARMED | `----` | LED1 ติดค้าง | เงียบ |
| ARMING | นับถอยหลัง 10 | LED2 กระพริบ 2 Hz | บี๊บทุกวินาที |
| ARMED | `On` | LED2 กระพริบ 0.5 Hz · LED3 ติดขณะรอ PIR สงบ | เงียบ |
| TRIGGERED | นับถอยหลัง 15 | แสดงจำนวนรหัสที่กด | บี๊บถี่ขึ้นเมื่อใกล้หมดเวลา |
| ALARM | กระพริบ `ALAr` | ไล่วนทั้ง 4 ดวง | ไซเรนวนลูป |
| UNLOCK | `OPEn` | ติดครบ 4 ดวง | เสียงยืนยัน 3 โน้ต |

## การใช้งาน Timer และ Interrupt

ข้อกำหนดของโจทย์คือใช้ Timer/Counter และ Interrupt อย่างละอย่างน้อย 1 การทำงาน โครงงานนี้ใช้อย่างละ 3

| โมดูล | คาบเวลา | หน้าที่ |
|---|---|---|
| PIT ช่อง 0 | 2 ms | สแกนจอ 7-Segment ทีละหลัก (125 รอบ/วินาที) |
| PIT ช่อง 1 | 1 ms | ฐานเวลาระบบ และตรวจการปล่อยปุ่มเพื่อกำจัดสัญญาณเด้ง |
| FTM0 ช่อง 6 | แปรผัน | สร้างความถี่โน้ตดนตรีออกที่ขา PTA1 |

| Vector | ลำดับความสำคัญ | หน้าที่ |
|---|---|---|
| `PORTB_IRQHandler` | 3 | สวิตช์ S1–S3 (ขอบขาลง) |
| `PORTC_IRQHandler` | 3 | เซ็นเซอร์ PIR (ขอบขาขึ้น) |
| `PIT0 / PIT1` | 1 / 2 | ตัวจับเวลา |

ทุก ISR ทำงานสั้นที่สุด เพียงตั้งค่าธงสัญญาณ การตัดสินใจทั้งหมดอยู่ในลูปหลัก
และทุกตัวเรียก `__DSB()` หลังเคลียร์ธง เพื่อกันการเข้า ISR ซ้ำ

**โปรแกรมไม่มีการหน่วงเวลาแบบ blocking แม้แต่จุดเดียว**

## การเชื่อมต่อขาสัญญาณ

| อุปกรณ์ | Arduino | K64F | หมายเหตุ |
|---|---|---|---|
| LED1 – LED4 | D13 / D12 / D11 / D10 | PTD1 / PTD3 / PTD2 / PTD0 | Active LOW |
| สวิตช์ S1 / S2 / S3 | A1 / A2 / A3 | PTB3 / PTB10 / PTB11 | Active LOW, internal pull-up |
| Buzzer | D3 | PTA1 | ALT3 = FTM0_CH6 |
| 7-Segment LATCH / CLK / DATA | D4 / D7 / D8 | PTB23 / PTC3 / PTC12 | 74HC595 ×2 |
| PIR HC-SR501 OUT | D6 | PTC2 | หัวต่อ 3 ขาบนชีลด์ |

**หัวต่ออุปกรณ์ภายนอกบนชีลด์** อยู่มุมขวาล่าง เป็นบล็อก 3 คอลัมน์ × 4 แถว
คอลัมน์จากซ้ายไปขวา: `GND` · `+5V` · `สัญญาณ` — แถวจากบนลงล่าง: `D5` · `D6` · `D9` · `A5`

## ข้อควรระวังทางฮาร์ดแวร์

โมดูล Multi-Function Shield ออกแบบมาสำหรับระบบ 5 V แต่ FRDM-K64F ทำงานที่ 3.3 V

1. **ต้องถอดจัมเปอร์ J2 ออก** — จัมเปอร์นี้ต่อตัวต้านทาน pull-up 10 kΩ ของสวิตช์ขึ้นไปยัง +5 V
   ซึ่งเกินพิกัดของขา PTB3 / PTB10 / PTB11 โปรแกรมใช้ pull-up ภายในชิปแทน

2. **Buzzer ต้องปิดด้วยการตั้งขาเป็นอินพุต** — วงจรใช้ทรานซิสเตอร์ PNP ที่อิมิตเตอร์อยู่ที่ +5 V
   การสั่งขาเป็น HIGH ได้เพียง 3.3 V ทำให้ Veb = 1.7 V ซึ่งยังมากพอให้ทรานซิสเตอร์นำกระแส
   เสียงจึงไม่ดับสนิท ต้องตัดกระแสเบสด้วยการทำให้ขาเป็น high impedance

3. **ห้ามใช้ Potentiometer (A0) และซ็อกเก็ต DS18B20 (A4) โดยตรง** — ทั้งสองจุดอ้างอิง +5 V
   ต้องต่อวงจรแบ่งแรงดันก่อนเท่านั้น

4. **ตรวจแรงดันขา OUT ของ PIR ก่อนเสียบ** — บางรุ่นออก 5 V ต้องใส่ตัวแบ่งแรงดัน 10 kΩ + 20 kΩ

## การตั้งค่าโมดูล PIR

| จุดปรับ | ตั้งเป็น |
|---|---|
| Tx (เวลาเอาต์พุตค้าง) | **ต่ำสุด** ต้องสั้นกว่า `EXIT_DELAY_SEC` |
| Sx (ระยะตรวจจับ) | กลาง ๆ |
| จัมเปอร์ H / L | **H** |

โมดูลต้องการเวลาอุ่นเครื่องประมาณ 1 นาทีหลังจ่ายไฟ ก่อนจะทำงานได้นิ่ง

ขณะอยู่สถานะ ARMED ไฟ **LED3** จะติดค้างระหว่างที่ระบบรอให้สัญญาณ PIR ตกลงสู่ระดับต่ำ
ถ้า LED3 ไม่ยอมดับ แปลว่าค่า Tx ตั้งไว้ยาวเกินไป

## การ Build

### FRDM-K64F (Keil µVision 5)

1. สร้างโปรเจคใหม่ เลือกอุปกรณ์ `MK64FN1M0VLL12`
2. Manage Run-Time Environment → ติ๊ก `CMSIS: CORE` และ `Device: Startup`
3. เพิ่ม `src/main.c` เข้า Source Group
4. ใน `system_MK64F12.c` คงค่า `CLOCK_SETUP` ไว้ที่ `0` (โหมด FEI)
5. Project → Rebuild all target files → Download (F8)

ค่าความถี่บัสถูกสอบเทียบไว้ที่ `BUS_CLK_HZ = 20485760` โดยจับเวลาจริงเทียบกับตัวนับบนจอ

### Arduino UNO (ทางเลือก)

เปิด `src/arduino/EL334_SecurityStation/EL334_SecurityStation.ino` ด้วย Arduino IDE
เลือก Board เป็น Arduino UNO แล้ว Upload ได้เลย ไม่ต้องติดตั้งไลบรารีเพิ่ม
